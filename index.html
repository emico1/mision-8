Misión 8

Subsecuencia común más larga

Encontrar la secuencia más larga de elementos que aparece, en el mismo orden, dentro de dos secuencias, usando programación dinámica. Es la idea detrás de comandos como diff y de la comparación de cadenas de ADN.

Programación dinámica

misma recurrencia, distinta forma de guardar
Tabla completa - O(mn) tiempo y memoria
Memorización recursiva - O(mn)
Dos filas - O(mn), memoria O(min(m,n))
Hirschberg - O(mn), memoria O(m+n)
Conteo de LCS distintas - O(mn)

Para comparar

no reutilizan subproblemas
Fuerza bruta - O(2m n)
Recursión sin memoria - exponencial
Cada subproblema es un par de prefijos, los primeros i elementos de X y los primeros j de Y. Se mira solo el último elemento de cada prefijo. c[i][j] = 0 si i = 0 o j = 0 c[i][j] = c[i-1][j-1] + 1 si X[i] = Y[j] c[i][j] = máx(c[i-1][j], c[i][j-1]) si X[i] ≠ Y[j]

Subsecuencia contra subcadena

Una subsecuencia conserva el orden pero puede saltar elementos. Una subcadena además tiene que ser contigua.

Aplicación, comparar dos versiones de un archivo

Cada línea es un elemento. Las líneas de la LCS son las que no cambiaron, el resto se marca como borrado o agregado.

Dos cadenas de ADN aleatorias del mismo largo n, mejor de varias corridas. La recursión sin memoria solo se corrió hasta n = 16. En negritas la más rápida.

Subproblemas repetidos

Peor caso de la recursión, ninguna letra coincide y cada celda abre dos ramas. Se cuentan las llamadas para X y Y de largo n.

Versiónllamadasveces la tabla

La tabla tiene (n+1)² celdas. La recursión sin memoria vuelve a calcular las mismas celdas una y otra vez.
